## 📒 Descrição
Esta planilha foi gerada com o intuito de criar um controle financeiro prático, de fácil visualização e compreensão.
Os dados utilizados são fictícios mediante base de dados fornecida no material de apoio apenas para entendimento do conteúdo.

## 🤖 Tecnologias Utilizadas
- IA Generativa **[ChatGPT](https://chat.openai.com)** para pesquisa e demais orientações;
- Google Imagens para criação de ícones;
- Ferramenta Excel para edição e criação
